📎 Cara Menyematkan File Google Drive

  1. Buka file di Google Drive, klik "Bagikan" → "Salin Link" (pastikan akses "Siapa pun yang memiliki link").
  2. Tempelkan link pada kolom input yang tersedia di setiap slot pada halaman Materi & File.
  3. Klik tombol "📥 Sematkan" atau tekan Enter — file akan langsung tersimpan ke Spreadsheet & muncul preview di halaman.
  4. Klik tombol "👁 Buka Viewer" untuk membuka file di viewer khusus tanpa Google Drive.
  5. Link yang didukung: drive.google.com/file/d/FILE_ID/view, drive.google.com/open?id=FILE_ID, atau langsung File ID.
  6. Data otomatis tersinkronisasi saat berpindah perangkat.
💡 Tips: Pastikan link sharing permission sudah diset ke "Anyone with the link" agar file dapat diakses oleh semua siswa.
